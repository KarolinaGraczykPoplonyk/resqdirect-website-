# ResQ Direct — Vehicle Recovery & Transport Website

A responsive business website developed for **ResQ Direct**, a UK vehicle recovery and vehicle transport service based in Peterborough.

The project was designed and built from scratch to create a professional online presence for a new recovery and transport business.

## Live Website

https://resqdirect.co.uk

## Project Overview

The website provides information about vehicle recovery and transport services, including:

- Vehicle recovery
- Breakdown and accident recovery
- Non-running vehicle transport
- Local and long-distance vehicle transport
- Auction vehicle collection
- Garage and dealer transport
- Motorcycle transport
- Service-area information
- Real recovery and transport work
- Driver guides and informational articles

## Content & SEO

The website includes original service content and practical UK motoring guides designed to support both customers and organic search visibility.

Guide content is researched using authoritative sources where appropriate, including UK government and DVSA guidance.

## Development

The website was developed locally using Visual Studio Code and version controlled with Git and GitHub.

The production website is hosted separately using IONOS web hosting.
